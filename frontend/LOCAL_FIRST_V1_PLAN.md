# PlanBlindBox Mobile V1 — Local-first 改造记录

## 本次迁移决策

- 从全新本地数据库开始，不迁移 MySQL 中的任何旧数据。
- 核心功能最终必须不依赖 Spring Boot、MySQL、账号或网络。
- 本地数据库使用 SQLite；Flutter 通过 Repository/Service 访问，不允许页面直接拼 SQL。
- 云备份采用用户手动上传/恢复的完整快照；恢复前必须提示覆盖并保留本地安全副本。
- 在线社区、好友、Mod 市场不属于 Mobile V1 的运行前提。

## 本次已落地

1. 增加 `sqflite` 和 `path` 依赖。
2. 新增 `lib/data/local_database.dart`：
   - 新库名 `plan_blind_box_local.db`，首次安装创建空库。
   - 建立任务、任务记录、分类、习惯、习惯打卡、资产余额、资产流水、每日签到、盲盒、奖励、收藏品、库存、开盒记录、时间记录和应用元数据表。
   - 对常用查询字段建立索引，对日期打卡和资产来源建立唯一约束。
   - 启用 SQLite 外键和 busy_timeout。
   - 预置空资产账户和默认任务分类，不导入服务器数据。
3. 新增 `lib/local/local_growth_service.dart`：
   - 本地资产查询。
   - 事务内发放金币、经验、水滴并写资产流水。
   - 按原有 05:00 业务日规则实现每日签到；月初重置连续天数；7/14/21 天阶梯奖励。
   - 通过业务来源幂等键防止重复发奖。

## 重要状态说明

这只是本地化迁移的第一批基础代码，**尚未完成可独立运行的 Mobile V1**。现有页面仍有 TodayApi、HabitApi、ShopApi、StatsApi、CollectionApi 等 HTTP 调用。后续必须逐个迁移并接入本地数据库，全部完成后才能移除 `http` 依赖和服务端地址配置。
